# Garden of Thorn / 荆棘花园

一个双人对战卡牌游戏。
玩家从动态卡池中构筑 15 张卡组，管理能量与魔力两种资源，使用攻击、装备、技能、反制四类卡牌，率先将对手生命值降至 0 即获胜。
项目使用 Godot 开发，目标是实现局域网联机对战。

## 游戏特色

- **双资源系统**：能量每回合自动回复，魔力需通过卡牌积累，两种资源并行管理，丰富决策维度。
- **动态卡组构筑**：总卡池数量为 200+（持续变化中），玩家自选 15 张构成牌组，每局体验不同。
- **四类卡牌博弈**：攻击牌造成伤害，装备牌提供持续效果，技能牌提供一次性战术，反制牌可在对手回合响应。
- **回合外响应**：对手攻击时，可使用反制牌进行闪避、减伤或免疫，互动性强。
- **回合限时**：超过 20 回合未分胜负，则剩余生命值高者胜，避免无限拖延。

## 快速开始（开发者）

1. 安装 [Godot 4.x](https://godotengine.org/download/)。
2. 克隆本仓库：
   
    git clone https://github.com/Stickerbug/Garden-of-Thorn.git
   
3. 使用 Godot 导入项目文件夹。
4. 按 F5 运行项目。

当前仍在开发中。
